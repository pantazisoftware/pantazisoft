# FabricatorPro - Complete Tools Reference

**App Name:** FabricatorPro
**Platform:** iOS
**Developer:** Pantazi Eduard Marius Robert
**Monetization:** Freemium (Monthly Subscription or Lifetime One-Time Purchase)

## Angles & Cuts

| Tool | Access | Description |
|------|--------|-------------|
| Miter Calculator | FREE | Simple miter angle for frame joints. Calculates cut angle and cut length from joint angle and profile width. |
| Compound Miter | FREE | Two-plane cut: miter + bevel. For crown molding, sloped frames, roof structures. Calculates miter angle, bevel angle, and effective 3D angle. |
| Profile Join Angle | PRO | Cut angles for joining two profiles at arbitrary directions. Gap/overlap analysis included. |
| Bisector | FREE | Bisect an angle with offset calculation. Calculates bisector angle and profile offset. |
| Pythagoras / 3-4-5 | FREE | Right triangle solver, diagonal check ("Is my frame square?"), and general triangle (law of cosines). Includes 3-4-5 verification table for squareness checks. |

## Pipe Cuts

| Tool | Access | Description |
|------|--------|-------------|
| Round on Round | FREE | Saddle cut / fish mouth template. Calculates the intersection profile when a round branch pipe meets a round main pipe at any angle. Includes 2D developed template and 3D preview. |
| Round on Flat | FREE | Pipe cut at angle to a flat surface. Generates an elliptical cut template as a developed sine wave pattern. |
| Square on Square | PRO | Square tube intersection calculations. Flat pattern for each face (4 cuts) at any intersection angle. |
| Square on Round | PRO | Square tube on round pipe intersection. Each face of the square profile intersects the cylinder differently. |
| Y-Pipe Connector | PRO | Y-junction from same-size pipe. Calculates cut profiles for two branch pipes merging into one outlet. Includes 2D schematic and 3D preview. |

## Hoppers & Funnels

| Tool | Access | Description |
|------|--------|-------------|
| Truncated Cone | FREE | Round funnel / reducer flat pattern development. Calculates the annular sector (arc) needed to roll into a cone shape. Outputs slant height, developed radii, sector angle, and sheet size. |
| Truncated Pyramid | PRO | Square funnel flat pattern development. Generates 4 trapezoid panels with shared edges and fold lines. |
| Round to Square | PRO | Transition piece development from a round opening to a square opening. 4 flat triangles (corners) + 4 curved panels. |
| Rectangle to Round | PRO | Asymmetric transition piece from rectangular to round opening. Complex multi-panel development. |
| Auger Screw | PRO | Helical flight (screw/auger) flat pattern template. Calculates the annular sector needed for one complete revolution. Outputs developed inner/outer radii, sector angle, and material needed. |

## Gates & Fences

| Tool | Access | Description |
|------|--------|-------------|
| Bar Spacing | FREE | Evenly distribute vertical bars across a gate or fence section. Three modes: specify number of bars, maximum spacing (e.g., child-safety code), or target spacing. Calculates gap size, edge spacing, and center-to-center distance. |
| Sliding Gate Slope | FREE | Rail geometry on sloped terrain. Calculates height differences, post heights, ground clearance, and actual rail length when a sliding gate operates on uneven ground. |
| Gate Counterweight | PRO | Swing and cantilever gate balance calculator. Torque balance for counterweight mass and position. Calculates hinge loads with and without counterweight, and auto-close behavior. |

## Workshop

| Tool | Access | Description |
|------|--------|-------------|
| Cutting Optimizer | PRO | Bar cutting optimization to minimize material waste. Uses First Fit Decreasing bin-packing algorithm. Input stock length, kerf width, and a list of pieces (length, quantity, label). Outputs bar assignments, waste per bar, total material utilization percentage, and visual cut layout. |
| Gear Train RPM | PRO | Multi-stage gear train RPM calculator. Input motor RPM and gear teeth counts for each stage. Calculates output RPM, total ratio, torque, efficiency, and rotation direction. Supports simple and compound gear trains. |
| Hydraulic Cylinder | FREE | Cylinder force, bore, and pressure calculator. Three modes: force from pressure, bore from force, pressure from force. Includes extend/retract forces, speed, stroke time, and oil volume calculations. Supports both hydraulic and pneumatic systems. |

## Geometry & Tools

| Tool | Access | Description |
|------|--------|-------------|
| Polygon Calculator | FREE | Regular polygon dimensions and area. From number of sides and one dimension (side length, circumradius, or inradius), calculates all other dimensions, interior/exterior angles, area, and perimeter. |
| Circle Division | FREE | Divide a circle into N equal parts. Outputs coordinates of each division point, chord length, and angular spacing. Includes 1:1 scale wrap-around paper template for pipe marking. |
| Arc Length | FREE | Arc, chord, and sagitta calculations. Input any two of radius, arc angle, chord length, or sagitta to calculate the rest. |
| Weight Calculator | PRO | Material weight by profile type. Supports sheet, round pipe, square pipe, angle, flat bar, and round bar profiles. Materials include steel, stainless steel, aluminum, and copper with accurate densities. |
| Stair Calculator | PRO | Rise, run, and stringer length calculator. Calculates number of steps, riser height, total run, stringer length, and angle. Includes Blondel comfort formula verification. |
| Thermal Expansion | PRO | Length change with temperature. Calculates linear expansion for steel, stainless steel, aluminum, and copper given original length and temperature change. |

## Utilities

| Tool | Access | Description |
|------|--------|-------------|
| Unit Converter | FREE | Universal converter for length (mm/cm/m/inch/feet/yard with fractional inch display), area, weight, pressure, temperature, and torque. All fields update live as you type. |
| Drill & Tap Chart | FREE | Searchable reference table for metric (M2-M30) and imperial (UNC/UNF) thread sizes. Shows tap drill diameter, clearance drill (close/free fit), pitch/TPI, and minor/major diameters. |
| Bolt Torque Chart | FREE | Tightening torque reference by bolt size (M5-M30) and strength class (4.6, 5.8, 8.8, 10.9, 12.9). Includes dry and lubricated values, clamp force, and wrench size. |
